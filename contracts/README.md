# Shared construction contracts

This directory is for reviewed interface/schema contracts, not department implementation code. No business exchange is implemented by this index.

Each contract needs: unique ID/version/status, baseline process sources, responsible systems/accounts, request/response/acknowledgement semantics, exact subject/version/grain, permissions, dates/time zones, currency/units, idempotency/native identifiers, state transitions, rejection/correction/revocation behavior, privacy, lineage, tests and evidence.

Separate operational Owner decisions from departmental analytics exports. Separate economic obligations from payment observations and ETL reports. Required upcoming artifacts: schema/RLS boundaries; initial actual administrator authorization; governed command envelopes; department marts and approved analytical export source-to-target mappings. SCHEMA-CONTRACTS owns their first reviewed draft, not autonomous live schema application.
